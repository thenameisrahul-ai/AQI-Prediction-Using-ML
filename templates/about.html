About This Project

AirPulse — Next-Day AQI Forecasting

AirPulse combines real-time data from the World Air Quality Index (WAQI) API with a machine-learning model trained on years of Indian city pollution records to predict tomorrow's Air Quality Index — giving you actionable health insights before the day begins.

How It Works

01

Live Data Fetch

Real-time pollutant readings are fetched from the WAQI API for the selected city — PM2.5, PM10, CO, SO₂, NO₂, and O₃.

02

Feature Engineering

Missing pollutants are filled with city-level medians. Temporal features (month, day-of-week) are added to capture seasonal and weekly patterns.

03

Standardisation

The 14-feature vector is scaled using a pre-fitted StandardScaler (fit on training data only) to prevent data leakage and ensure correct model input.

04

XGBoost Prediction

The scaled vector is passed to a trained XGBoost regressor (500 trees) which outputs a continuous next-day AQI value, mapped to an AQI category.

Dataset

Air Quality Data in India

The training dataset is sourced from the Central Pollution Control Board (CPCB) via Kaggle. It contains daily averaged pollutant readings and AQI values for 29 major Indian cities spanning 2015–2020.
